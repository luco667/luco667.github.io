01 / DOCUMENT IDENTIFICATION

Topic: Changing the Windows selection color

Method: Windows Registry edit

Tool: Registry Editor (regedit)

Registry key: HKEY_CURRENT_USER\Control Panel\Colors

Values modified: Hilight, HilightText

Risk level: Moderate (backup required)

Document type: Technical documentation

02 / OVERVIEW

The selection color is the color displayed when text or items are selected in Windows interface windows. It can be customized by editing two values stored in the Windows Registry.

Editing the registry gives more precise and advanced control over the interface than the standard settings. However, manual changes can be risky, so a backup must be made beforehand.

Primary objectives

  • Open the Registry Editor safely.
  • Locate the key that stores interface colors.
  • Change the selection background and text colors.
  • Apply the changes to the current session.

03 / REGISTRY ARCHITECTURE

The color settings of the Windows interface are stored in the current user's registry hive. The Colors key contains the parameters for the colors used across the interface.

Key path

HKEY_CURRENT_USER
└── Control Panel
    └── Colors
        ├── Hilight        (selection background)
        └── HilightText    (selected text color)

This diagram shows only the values relevant to this procedure. The Colors key contains many other interface color settings.

04 / COLOR VALUES

Hilight — Selection background

Defines the background color of a selected element. Double-click this value to edit it. The color is entered as an RGB code, for example 0 0 255 for blue.

HilightText — Selected text

Defines the color of the text inside a selected element. For example, 255 255 255 produces white text.

Value format

Each value is three numbers between 0 and 255, separated by spaces, representing red, green and blue in that order.

05 / PREREQUISITES AND BACKUP

Editing the registry can be risky. A mistake may affect the behavior of the system, so always back up before making changes.

Recommended precautions

  • Export the Colors key to a .reg file.
  • Note the original Hilight and HilightText values.
  • Modify only the values described in this document.
  • Create a system restore point if needed.

06 / PROCEDURE

Step 1 — Open the Registry Editor

1. Press Win + R to open the Run dialog
2. Type regedit
3. Press Enter

Step 2 — Navigate to the key

HKEY_CURRENT_USER\Control Panel\Colors

This key contains the settings for the colors used in the Windows interface.

Step 3 — Edit the color values

  • In the right pane, locate Hilight and HilightText.
  • Double-click Hilight to change the selection background color.
  • Double-click HilightText to change the selected text color.
  • Enter each color as an RGB code (for example 0 0 255).

07 / APPLYING THE CHANGES

Once the values are modified, close the Registry Editor. The new colors may not appear immediately.

Options to apply the changes

Option A: Restart the PC
Option B: Restart Windows Explorer
  1. Press Ctrl + Shift + Esc (Task Manager)
  2. Right-click "Windows Explorer"
  3. Select "Restart"

08 / RGB COLOR CODES

RGB values are three numbers between 0 and 255, representing the amount of red, green and blue in the color.

Reference values

0 0 255      pure blue
255 0 0      pure red
0 255 0      pure green
255 255 0    pure yellow
0 0 0        black
255 255 255  white

09 / PRACTICAL EXAMPLE

To get a light blue selection with white text, enter the following values: 

Hilight      : 173 216 230   (light blue)
HilightText  : 255 255 255   (white text)

10 / NOTES AND PRECAUTIONS

Alternative method

The selection color can also be changed through the Windows "Colors and window appearance" settings. Editing the registry offers more precise and advanced control over the interface.

Best practices

  • Always back up the registry before editing.
  • Keep sufficient contrast between background and text.
  • Restart Explorer or the PC to apply changes.
  • Restore the original values if the result is unsatisfactory.
